# Hub для iPhone

Это оболочка: приложение, которое открывает твой сайт voevodin-hub.ru во весь экран.
Добавляет вход по Face ID, число просроченных дел на значке и уведомления с телефона.

## Как получить .ipa (один раз, потом обновлять нужно только при изменении оболочки)
1. Зарегистрируйся на github.com (бесплатно).
2. Нажми «+» → New repository. Имя: hub-ios. Выбери **Public**. Нажми Create repository.
3. На странице репозитория: «uploading an existing file». Перетащи внутрь **содержимое папки hub-ios**
   (папку Hub, файл project.yml, .gitignore). Нажми Commit changes.
4. Файл сборки: Add file → Create new file. В имени файла напиши `.github/workflows/build.yml`
   (слэши создадут папки сами). Вставь текст из файла build.yml. Commit changes.
5. Вкладка **Actions** → слева «Build IPA» → кнопка «Run workflow». Сборка идёт 4–8 минут.
6. Когда появится зелёная галочка: открой запуск → внизу раздел Artifacts → скачай **Hub-ipa**.
   Внутри архива лежит Hub.ipa.
7. Перекинь Hub.ipa на iPhone (iCloud Drive / AirDrop / Telegram себе) и открой в ESign.
   Подпиши своим сертификатом и установи.
8. При первом запуске разреши уведомления и Face ID.

Если сборка упала (красный крестик), открой запуск, скачай артефакт build-log и пришли мне текст ошибки.
